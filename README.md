# Soccer Match Prediction

## Overview
This project implements a machine learning model to predict the outcome of soccer matches based on player ratings and potential. It utilizes historical match data to train the model and make predictions on future matches.

## Dataset
The dataset includes information on past soccer matches, focusing on the following features:

**home_avg_rating**: Average rating of the home team players

**away_avg_rating**: Average rating of the away team players

**home_avg_potential**: Average potential of the home team players

**away_avg_potential**: Average potential of the away team players

These features are used to train the model and generate predictions on match outcomes.

## Model Training & Evaluation

The dataset is preprocessed, and features are extracted.

A machine learning model is trained using the given features.

The model's accuracy is evaluated using appropriate metrics such as accuracy, precision, and recall.
